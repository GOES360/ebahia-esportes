# ÉBahia Esportes

Aplicação esportiva do Portal ÉBahia. Interface responsiva com placares, futebol baiano, futebol nacional/internacional, basquete e áreas para demais modalidades.

## Dados
A primeira integração de placares usa a API pública SportScore, com atribuição visível conforme os termos do provedor. A interface possui fallback e não inventa resultados quando a fonte estiver indisponível.
